# Executive Briefing

Copy the [template](templates/executive-briefing.txt) into a new report, then fill
it from the user's notes or existing workspace reports.

- Read previous briefings and relevant reports for the same subject, if available.
  Build on their findings and open decisions/actions, apply new facts, and leave
  source reports unchanged. Mark items without updates "No update provided".
- Lead with the main message and business implication. Keep only findings that
  matter to the audience and separate recommendations from confirmed facts.
- State the decision needed, decision maker, and deadline where supplied.
  For informational briefings, use "For information; no decision requested".
- List next steps with supplied owners and dates, and record source report paths.
