# Project Status Report

Copy the [template](templates/project-status-report.txt) into a new report, then
fill it with the project's notes and reporting dates.

- Read the preceding period's report, if available. Carry forward milestones,
  open risks/issues, actions, and pending decisions; leave that report unchanged.
- Add this period's progress and summarize what changed. Do not repeat previous
  accomplishments as new or mark actions complete without an update.
- Preserve action owners and due dates. Mark overdue actions and use
  "No update provided" where carried-forward items lack fresh information.
- Explain RAG status: Green = on track, Amber = at risk, Red = delivery problem.
  Use "To confirm" when current evidence is missing.
- Record the preceding report's path in Sources and Gaps.
